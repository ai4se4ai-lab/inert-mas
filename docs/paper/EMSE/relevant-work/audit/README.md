# Taxonomy audit trail (Section 3 of the manuscript)

Run the whole pipeline with `bash analysis/taxonomy_pipeline.sh` (offline, from the cached API responses in
`../snowball/cache/`) or `ELSEVIER_API_KEY=... bash analysis/taxonomy_pipeline.sh --fetch` to query OpenAlex and Scopus for anything not
yet cached. It writes every file below and the count macros used in the manuscript (`\NCorpus` and others).

Every file is regenerated by `python analysis/taxonomy_audit.py` (also run by `analysis/run_all.sh`)
from the raw search exports in `..` and the coding spec at the top of the script. Steps 1-3 are
computed; steps 4-10 are author coding, recorded explicitly so that each judgment can be checked.

| Step | File | What it shows | Paper |
|---|---|---|---|
| 1 Search | `01_search_records.csv` | all 143 records returned by Q1 (72) and Q2 (71), with rank, year, venue, library, URL | Fig. 3, Sec. 3.4 |
| 2 Deduplication | `02_deduplication.csv` | normalized title of each record, 6 duplicates and the record each duplicates | Fig. 3 |
| 3 Screening | `03_screening.csv` | 137 unique records, decision (127 include, 10 exclude), criterion (I1 / E1), the decision of a transparent title rule (agrees on 132), title facets, and a note for the 5 inclusions the rule misses | Sec. 3.4 |
| 4 Codebook | `04_leaf_codebook.csv` | definition of each of the 18 leaves and the INERT element it informs | Fig. 4 |
| 5 Classification | `05_classification.csv` | leaf of each of the 127 studies, where the paper cites it, query and library | Fig. 4 |
| 6 Channel tree | `06_channel_tree.csv` | 14 attack forms with channel, control class, mechanism, property, criterion and supporting studies (2 forms derived from the coordination model, no corpus study) | Fig. 2 |
| 7 Evidence | `07_evidence_table.csv` | rows of Table 2 | Table 2 |
| 8 Requirements | `08_requirements.csv` | R1-R8 with channels, attack forms, property and mechanism | Sec. 3.6 |
| 9 Gap matrix | `09_gap_matrix.csv` | Table 3 with a rationale per rating | Table 3 |

| 11 Supplement | `11_supplementary_studies.csv` | 22 works found by targeted searches, with verified identifiers, and whether the snowballing found them independently (those belong to the corpus) | Sec. 10 |

`summary.json` recomputes the counts the paper reports and lists any citation key that does not resolve
and checks that Tables 2 and 3 of the manuscript match `07_evidence_table.csv` and `09_gap_matrix.csv` (the script exits non-zero on any unresolved key, unexplained screening difference or table mismatch).

Manual decisions for the snowballing studies are a coding spec in `../snowball/manual_screening.csv`; the snowballing parameters (window, link threshold) are constants at the top of `analysis/snowball.py`, and `snowball_summary.json` reports the number of included studies for every link threshold from 1 to 6.

Scopus contributes forward links (a search of reference lists for each seed's title, `REF("title")`, because the key has no entitlement to reference lists or citation links) and the two queries in Boolean form (`SCOPUS_QUERIES` in `analysis/snowball.py`). Scopus records are merged with OpenAlex by DOI and title, abstracts come from OpenAlex, and records without an OpenAlex entry are screened on the title. `snowball_summary.json` reports the overlap between the Scopus search and the other routes.

All manual screening and classification decisions in `../snowball/manual_screening.csv` (LLM-assisted) were reviewed and confirmed by the author on 2026-11-24.
